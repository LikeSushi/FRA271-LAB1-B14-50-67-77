วัตถุประสงค์ 
1. การออกแบบการทดลองตามหลักวิทยาศาสตร์ 
- ใช้กระบวนการทางวิทยาศาสตร์ในการส ารวจพฤติกรรมและปรากฏการณ์ของ Sensor 
- บันทึก สรุป และอภิปรายผลการทดลองอย่างเป็นระบบ 
- ประยุกต์ใช้  MATLAB ในการเก็บข้อมูล  รวมทั้งวิเคราะห์ความเที่ยงตรง  (Precision) และความแม่นย า  
(Accuracy) 
- ตรวจสอบผลการทดลองกับทฤษฎีและแหล่งข้อมูลที่เชื่อถือได้ เช่น Datasheet ของอุปกรณ์ 
- แสดงผลการทดลองในรูปแบบกราฟและตารางที่เหมาะสม 
2. ความเข้าใจหลักการท างานของ Sensor 
- อธิบายกระบวนการแปลงสัญญาณจากปริมาณทางฟิสิกส์เป็นสัญญาณไฟฟ้าได้ครบถ้วน 
- ตัวอย่าง: การวัดความเร็วเชิงมุมด้วย Incremental Encoder, การแปลงแรงดันไฟฟ้าเป็นค่าน ้าหนักใน Load 
Cell 
3. การก าหนดตัวแปรและสมมติฐาน 
- ระบุตัวแปรต้น ตัวแปรตาม และตัวแปรควบคุมได้อย่างถูกต้อง 
- ตั้งสมมติฐานที่สอดคล้องกับตัวแปรและมีทฤษฎีรองรับ 
- อ้างอิงข้อมูลจากทฤษฎีทางฟิสิกส์หรือ Datasheet ของอุปกรณ์ 
4. การด าเนินการทดลอง 
- ออกแบบขั้นตอนการทดลองด้วยตนเองตามหลักวิทยาศาสตร์ 
- ใช้ Simulink, MATLAB Live Script (.mlx) และบอร์ดทดลองที่จัดเตรียมไว้ 
- ท าการทดลองซ ้าเพื่อความน่าเชื่อถือของข้อมูล 
- อธิบายที่มาและเหตุผลของผลการทดลองที่ได้ 
5. การเขียนรายงานทางวิทยาศาสตร์ 
- ใช้สัญลักษณ์และสมการทางวิทยาศาสตร์อย่างถูกต้อง 
- จัดรูปแบบเอกสารตามมาตรฐานสากล (การเว้นวรรค ขอบกระดาษ ระยะบรรทัด) 
- น าเสนอข้อมูลอย่างเป็นระเบียบและอ่านง่าย

Lab 1.1 
Potentiometer 
สามารถอธิบายหลักการท างานของ Potentiometer ได้ 1.0 
สามารถระบุชนิดของ Potentiometer ทั้งหมดได้ 1.0 
สามารถอธิบายคุณสมบัติและความเป็นเชิงเส้นของ Potentiometer แต่ละชนิดได้ 1.0 
สามารถอธิบายการตอบสนองของ Potentiometer แต่ละชนิดได้ (การตอบสนองของแรงดันไฟฟ้าขาออกต่อ
ระยะทาง หรือองศาการหมุนของ Potentiometer) 1.0 
สามารถออกแบบและสร้างวงจร Schmitt Trigger ใน Simulink ได้ 1.0 
สามารถก าหนดค่า Upper และ Lower Threshold ที่เหมาะสม พร้อมให้เหตุผลได้ 0.5 
สามารถแปลงสัญญาณ Analog เป็นสัญญาณ Digital ตามรูปแบบวงจร Schmitt Trigger ได้ โดยแสดงให้
เห็นว่าสัญญาณ Output แปรผันตามสัญญาณ Input แบบ Real Time 1.0 
สามารถแสดงให้เห็นถึงการท าซ ้า และความสมเหตุสมผลของการทดลอง 0.5 
ความเหมาะสมของการตั้งจุดประสงค์ สมมติฐาน ตัวแปร และเอกสารและงานวิจัยที่เกี่ยวข้อง 1.0 
สามารถอธิบายขั้นตอนการด าเนินงานได้อย่างครบถ้วน 0.5 
สามารถแสดงผลการทดลอง สรุปผลการทดลอง และอภิปรายผล ได้อย่างสมเหตุสมผลและครบถ้วน 1.0 
ความเหมาะสมของข้อเสนอแนะและเอกสารอ้างอิง 0.5 
สามารถอธิบายโปรแกรมได้อย่างครบถ้วน เข้าใจถึงแนวคิดและหลักการท างาน (ภาคผนวก) 0.5

Raw Signal, Magnetic Flux Density ในหน่วย SI Derived ได้ 1.0

สามารถแสดงผลการทดลอง สรุปผลการทดลอง และอภิปรายผล ได้อย่างสมเหตุสมผลและครบถ้วน 1.0

Lab 1.4 
Load Cell 
สามารถอธิบายหลักการท างานของ Load cell, วงจร Wheatstone bridge, Strain Gauge และ 2 Op-
amps Differential Amplifier ได้ 1.5 
สามารถอธิบายค่าสัญญาณ Output ของ Load Cell เมื่อแรงที่กระท าต่อ Load Cell เปลี่ยนแปลงไปได้ 1.0

สามารถอธิบายความสัมพันธ์ระหว่างค่า Gain และค่าความต้านทานได้ 1.0 
สามารถอธิบายกระบวนการ Signal Conditioning และ Calibration ทั้งหมดได้ 1.0 
สามารถวิเคราะห์ Saturation ที่เกิดขึ้นได้ 1.0 
สามารถแสดงให้เห็นถึงการเปรียบเทียบค่าที่ได้กับเครื่องชั่ง Digital ได้ 0.5 
สามารถอธิบายสาเหตุของความคลาดเคลื่อนที่ท าให้ค่าที่วัดได้ไม่ตรงกับเครื่องชั่ง Digital ได้ 1.0 
สามารถแสดงให้เห็นว่าสัญญาณ Output แปรผันตามสัญญาณ Input แบบ Real Time โดยมี Output เป็น
น ้าหนัก ในหน่วย SI Derived 1.0 
สามารถแสดงให้เห็นถึงการท าซ ้า และความสมเหตุสมผลของการทดลอง 0.5 
ความเหมาะสมของการตั้งจุดประสงค์ สมมติฐาน ตัวแปร และเอกสารและงานวิจัยที่เกี่ยวข้อง 1.0 
สามารถอธิบายขั้นตอนการด าเนินงานได้อย่างครบถ้วน 0.5
