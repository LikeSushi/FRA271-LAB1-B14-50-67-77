# 1. บทนำ (Introduction)

### 1.1 ที่มาและความสำคัญ
ในระบบหุ่นยนต์และระบบอัตโนมัติ การตรวจวัดแรงกด (Force) และน้ำหนัก (Mass) มีความสำคัญอย่างยิ่งต่อการควบคุมการจับยึดวัตถุ (Gripping Force Control) การชั่งน้ำหนักในสายการผลิตอัตโนมัติ และการตรวจจับการสัมผัสเพื่อความปลอดภัย (Safety Collision Detection) อุปกรณ์ตรวจวัดแรงที่นิยมใช้อย่างแพร่หลายคือ **Single Point Load Cell** ซึ่งทำงานโดยอาศัยปรากฏการณ์การเปลี่ยนแปลงความต้านทานตามความเครียด (Piezoresistive Effect) ของสเตรนเกจ (Strain Gauge) 

อย่างไรก็ตาม สัญญาณไฟฟ้าผลต่าง (Differential Voltage) $V_d = V^+ - V^-$ ที่ได้จากวงจร Wheatstone Bridge ของโหลดเซลล์มีขนาดเล็กมากในระดับมิลลิโวลต์ (ซึ่งวัดค่าจริงในการทดลองได้ $4.3\text{ mV}$) ซึ่งไม่สามารถนำไปต่อเข้ากับพอร์ต Analog-to-Digital Converter (ADC) ของไมโครคอนโทรลเลอร์ได้โดยตรง จำเป็นต้องผ่านกระบวนการปรับสภาพสัญญาณ (Signal Conditioning) ด้วยวงจรขยายสัญญาณเครื่องมือวัดความแม่นยำสูง (Instrumentation Amplifier) เช่น ไอซี **INA125** เพื่อขยายสัญญาณขึ้นสู่ระดับโวลต์ พร้อมทั้งกำจัดสัญญาณรบกวนร่วม (Common-Mode Noise) การทดลองนี้จึงมุ่งเน้นศึกษาคุณลักษณะการแปลงสัญญาณ การหาค่าอัตราขยายที่เหมาะสม การสอบเทียบ (Calibration) การวิเคราะห์สภาวะอิ่มตัว (Saturation) และการประเมินความแม่นยำเทียบกับเครื่องชั่งดิจิทัลมาตรฐาน

### 1.2 จุดประสงค์การทดลอง
1. เพื่อศึกษาหลักการทำงานของ Single Point Load Cell, สเตรนเกจ (Strain Gauge), วงจรบริดจ์แบบเต็มรูปแบบ (Full-Bridge Wheatstone Bridge) และวงจรขยาย 2 Op-Amps Differential Amplifier ในไอซี INA125
2. เพื่อคำนวณและปรับตั้งค่าอัตราขยาย (Gain) ที่เหมาะสมผ่านตัวต้านทานปรับค่าได้ $R_G$ และอธิบายความสัมพันธ์ระหว่างค่า Gain กับความต้านทาน
3. เพื่อศึกษากระบวนการปรับสภาพสัญญาณ (Signal Conditioning) และสร้างสมการการสอบเทียบ (Calibration Model) สำหรับแปลงค่าแรงดันแอนะล็อกเป็นมวล (kg) และแรงกด (N)
4. เพื่อวิเคราะห์และระบุขอบเขตสภาวะอิ่มตัว (Saturation Analysis) ทั้งทางกลและทางไฟฟ้า
5. เพื่อเปรียบเทียบความถูกต้องของโหลดเซลล์กับเครื่องชั่งดิจิทัลมาตรฐาน และวิเคราะห์สาเหตุของความคลาดเคลื่อน
6. เพื่อประเมินความสามารถในการวัดซ้ำ (Repeatability) ของระบบจากการทดลอง 3 รอบซ้ำ

### 1.3 สมมติฐานการทดลอง
1. แรงดันเอาต์พุต ($V_{out}$) ของวงจรขยาย INA125 จะแปรผันตรงเป็นเชิงเส้นกับมวลที่กระทำ ($m$) ตลอดช่วงการทำงานปกติ ($R^2 > 0.99$)
2. เมื่อภาระโหลดเข้าใกล้พิกัดสูงสุด ($10\text{ kg}$) ระบบจะเริ่มเบี่ยงเบนออกจากความเป็นเชิงเส้นและเกิดสภาวะอิ่มตัว (Saturation) เนื่องจากข้อจำกัดการโก่งตัวเชิงกล (Mechanical Overload Protection Gap) ของคานโหลดเซลล์
3. การทดลองซ้ำจำนวน 3 รอบจะให้ค่าที่มีความสอดคล้องกันสูง โดยมีค่า Repeatability Error ไม่เกิน $0.5\% \text{ FS}$

### 1.4 ตัวแปรการทดลอง
- **ตัวแปรต้น (Independent Variable):** มวลที่กระทำต่อโหลดเซลล์ ($m$) จำนวน 11 พิกัด ตั้งแต่ $0.988\text{ kg}$ ถึง $9.961\text{ kg}$ (เทียบเท่าแรงกด $9.69 - 97.68\text{ N}$)
- **ตัวแปรตาม (Dependent Variables):** 
  1. แรงดันเอาต์พุตแอนะล็อก ($V_{out}$) จากไอซี INA125 (โวลต์: V)
  2. ค่าดิจิทัลจากการแปลงของ ADC 12-bit บนไมโครคอนโทรลเลอร์ STM32 (Counts)
  3. ค่าน้ำหนักที่คำนวณได้ผ่านสมการสอบเทียบย้อนกลับ ($m_{calc}$)
- **ตัวแปรควบคุม (Controlled Variables):**
  1. แรงดันไฟเลี้ยงระบบ ($V_{supply} = 3.30\text{ V}$) จากรางจ่ายไฟเรกูเลตของบอร์ด STM32
  2. ค่าความต้านทานอัตราขยาย $R_G$ ของวงจร INA125 (คงที่ตลอดการทดสอบ)
  3. ตำแหน่งการวางโหลดบนถาดรับน้ำหนัก 3D-Printed (พยายามวางให้อยู่กึ่งกลาง)
  4. อุณหภูมิแวดล้อมภายในห้องปฏิบัติการ
  5. เวลาในการบันทึกข้อมูลคงที่ 15 วินาทีต่อพิกัดน้ำหนักที่ความถี่สุ่ม $1\text{ kHz}$

# 2. เอกสารและงานวิจัยที่เกี่ยวข้อง (Literature Review)

### 2.1 หลักการทำงานของ Strain Gauge และ Single Point Load Cell
โหลดเซลล์รุ่น YZC-131A เป็นคานรับแรงดัดแบบขนาน (Parallel Guided Bending Beam) ทำจากอะลูมิเนียมอัลลอยด์ เมื่อมีแรงกดภายนอก $F$ มากระทำ คานจะเกิดความเค้นและความเครียด ($\varepsilon$) ซึ่งส่งผลให้สเตรนเกจแบบฟอยล์โลหะที่ติดตั้งบนผิวคานเปลี่ยนรูป ทำให้ความต้านทานเปลี่ยนไปตามหลัก Piezoresistive Effect [7]:
$$\frac{\Delta R}{R} = GF \cdot \varepsilon$$
โดยค่า Gauge Factor ($GF$) ของสเตรนเกจโลหะทั่วไปมีค่าประมาณ $2.0$

### 2.2 วงจร Full-Bridge Wheatstone Bridge และการชดเชยอุณหภูมิ
ภายในโหลดเซลล์ตัวนี้ใช้สเตรนเกจ 4 ตัว ต่อเป็นวงจรบริดจ์เต็มรูปแบบ (Full-Bridge) โดยจัดวางให้ 2 ตัวรับแรงดึง ($+\Delta R$) และอีก 2 ตัวรับแรงอัด ($-\Delta R$) ตามการวิเคราะห์ของ Pallás-Areny และ Webster [7] การต่อแบบ Full-Bridge มีข้อได้เปรียบที่สำคัญคือ:
1. **ความไวสูงสุด (4x Sensitivity):** แรงดันผลต่างของบริดจ์คำนวณได้จาก:
   $$V_d = V_{IN}^+ - V_{IN}^- = V_{exc} \left(\frac{\Delta R}{R}\right) = V_{exc} \cdot GF \cdot \varepsilon$$
   ซึ่งให้ขนาดสัญญาณสูงกว่า Quarter Bridge ถึง 4 เท่า
2. **การชดเชยอุณหภูมิในตัวเอง (Intrinsic Temperature Compensation):** เมื่ออุณหภูมิแวดล้อมเปลี่ยน ความต้านทานที่ขยายตัวจากความร้อน ($\Delta R_{\Delta T}$) จะเกิดขึ้นเท่ากันทุกแขนบริดจ์ ทำให้ผลต่างแรงดันกึ่งกลางหักล้างกันเอง จึงไม่เกิด Zero Drift
3. **การรักษาความเป็นเชิงเส้น:** พจน์ไม่เป็นเชิงเส้นของสมการบริดจ์จะหักล้างกันเองอย่างสมบูรณ์

### 2.3 วงจรขยาย INA125 (2 Op-Amps Differential Amplifier)
ไอซี INA125 [2] ออกแบบด้วยโครงสร้างวงจรขยายสัญญาณเครื่องมือวัดแบบ 2 Op-Amps ร่วมกับแหล่งจ่ายแรงดันอ้างอิงความแม่นยำสูง (Precision Voltage Reference) มีคุณสมบัติเด่นคือ:
- **Input Impedance สูงมาก ($> 10^9\ \Omega$):** ทำให้ไม่มีกระแสไหลเข้าขั้วอินพุต จึงไม่เกิดผลกระทบโหลด (Loading Effect) ไปรบกวนความต้านทานของวงจร Wheatstone Bridge
- **Common-Mode Rejection Ratio (CMRR > 100 dB):** ช่วยตัดแรงดันไฟเลี้ยงกึ่งกลาง ($V_{exc}/2 \approx 1.65\text{ V}$) และสัญญาณรบกวนร่วมออกไป
- **สมการอัตราขยาย (Gain Equation):** กำหนดด้วยตัวต้านทานภายนอก $R_G$ เพียงตัวเดียว:
  $$G = 4 + \frac{60\text{ k}\Omega}{R_G}$$

### 2.4 กลไกการเกิด Saturation และ Gain Compression เชิงกล
งานวิจัยของ Barbato และคณะ [1] ได้ศึกษาวิจัยพฤติกรรมของโหลดเซลล์สเตรนเกจเมื่อรับภาระเกินพิกัด พบว่าโครงสร้างคานรับแรงจะมีระยะช่องว่างจำกัดเชิงกล (Mechanical Overload Protection Gap) เมื่อคานโก่งตัวจนแตะกับฐานรองรับ ความแข็งเกร็งประสิทธิผลของโครงสร้างจะพุ่งสูงขึ้นอย่างรวดเร็ว (Non-linear Stiffening) ทำให้ความไวในการเปลี่ยนรูป ($\Delta \varepsilon / \Delta F$) ลดลงอย่างรวดเร็ว เกิดปรากฏการณ์บีบอัดอัตราขยาย (Gain Compression) 

ขณะเดียวกัน ด้านวงจรไฟฟ้า เอกสารข้อมูลของ Texas Instruments [2] ระบุว่าแรงดันเอาต์พุตสูงสุดของ INA125 บนระบบ Single Supply จะสวิงได้สูงสุดประมาณ $V^+ - 1.2\text{ V}$ หากแรงดันเกินกว่านี้จะเกิด Electrical Clipping Saturation

### 2.5 ปรากฏการณ์ Creep, Hysteresis และ Four-Corner Error
- **Creep (การคืบ):** Ramos และคณะ [3] สร้างแบบจำลองพบว่าเนื้ออะลูมิเนียม 6061-T6 และชั้นกาวประสานอีพ็อกซีของสเตรนเกจจะเกิดการคลายตัวหยุ่นหนืด (Viscoelastic Relaxation) ภายใต้แรงกดคงที่ ทำให้แรงดันค่อยๆ ไต่ขึ้นตามเวลา (Positive Creep Drift)
- **Mechanical Hysteresis:** Ferrero และคณะ [4] ชี้ว่าการสูญเสียพลังงานจากการเสียดทานภายในผลึกโลหะทำให้เส้นโค้งขาขึ้นและขาลงไม่ทับกัน และเมื่อยกโหลดออกจะเกิดค่าแรงดันตกค้างที่จุดศูนย์ (Zero-Return Offset)
- **Four-Corner Error (Off-Center Loading):** Peters และคณะ [5] รวมถึง Li และ Zhang [6] พิสูจน์ว่าความคลาดเคลื่อนจากการตัดเฉือนจุดคอดทั้ง 4 จุดที่ไม่เท่ากันอย่างสมบูรณ์ ($\Delta t \neq 0$) จะก่อให้เกิดแรงบิดแฝง (Parasitic Torsional Moment) เมื่อวางน้ำหนักไม่ตรงกึ่งกลางคาน

### 2.6 การชดเชยความไม่เป็นเชิงเส้นและมาตรฐานสากล OIML R60
- **มาตรฐาน OIML R60 [9]:** เป็นมาตรฐานสากลกำกับดูแลโหลดเซลล์ โดยกำหนดเกณฑ์ Maximum Permissible Error (MPE) และการทดสอบ Repeatability ไม่น้อยกว่า 3 รอบ เพื่อจำแนกชั้นความแม่นยำ (Class A, B, C, D)
- **การชดเชยด้วยสมการพหุนาม:** Betta และคณะ [10] และ Patra และคณะ [11] นำเสนอว่าการประยุกต์ใช้สมการพหุนามอันดับสอง (2nd-Order Polynomial) หรือ Look-Up Table ในซอฟต์แวร์สามารถลดความคลาดเคลื่อนไม่เป็นเชิงเส้นลงได้มากกว่า 60% – 85% เมื่อเทียบกับสมการเส้นตรง

# 3. อุปกรณ์และวิธีการทดลอง (Apparatus & Methodology)

### 3.1 รายการอุปกรณ์การทดลอง
1. Single Point Load Cell รุ่น YZC-131A (พิกัด 10 kg, ความไว $1.0\text{ mV/V}$)
2. ไอซีขยายสัญญาณ INA125 Instrumentation Amplifier
3. ตัวต้านทานปรับค่าได้แบบละเอียด Trimpot $100\text{ k}\Omega$ ชนิด 25 รอบ (Multi-turn)
4. ตัวต้านทานคงที่จำกัดกระแส $4.7\text{ k}\Omega$
5. บอร์ดไมโครคอนโทรลเลอร์ Nucleo STM32G474RE
6. ฐานบรรจุอุปกรณ์และแท่นรับน้ำหนัก 3D-Printed (LoadCellXplorer)
7. ถุงทรายและตุ้มน้ำหนักมาตรฐาน (11 พิกัด: $0.988 - 9.961\text{ kg}$)
8. เครื่องชั่งดิจิทัลมาตรฐานอ้างอิง (ความละเอียด $0.1\text{ g}$)
9. สายเชื่อมต่อวงจร (Jumper Wires) และสาย Micro USB

### 3.2 ขั้นตอนการดำเนินงาน
1. **การประกอบและต่อวงจร:** เชื่อมต่อสายโหลดเซลล์ 4 เส้นเข้ากับ INA125 โดยต่อ $E+$ (สายสีขาว) และ $E-$ (สายสีดำ) เข้ากับแหล่งจ่ายไฟ $3.3\text{ V}$ และกราวด์, ต่อสายสัญญาณ $A+$ (สายสีเขียว) และ $A-$ (สายสีแดง) เข้ากับขาอินพุต $V_{IN}^+$ และ $V_{IN}^-$
2. **การปรับตั้งค่า Gain:** ต่อ Trimpot 25 รอบเข้าที่ขา $R_G$ (ขา 8 และ 9) ปรับหมุนเพื่อตั้งค่า Gain ให้สอดคล้องกับค่าที่คำนวณได้ ($G \approx 500, R_G \approx 121\ \Omega$) โดยทดสอบวางโหลดสูงสุดเพื่อยืนยันว่าแรงดันเอาต์พุตไม่เกิน $2.0\text{ V}$
3. **การเชื่อมต่อกับ STM32 และ Simulink:** ต่อขาเอาต์พุต $V_O$ ของ INA125 เข้ากับขาแอนะล็อก $PA0$ (ADC1_IN1) ของบอร์ด STM32G474RE ตั้งค่าโมเดล Simulink/Waijung บันทึกข้อมูลด้วย Sampling Rate $1\text{ kHz}$
4. **การเก็บข้อมูลการทดลอง (3 รอบซ้ำ):**
   - ชั่งน้ำหนักถุงทรายด้วยเครื่องชั่งดิจิทัลเพื่อใช้เป็นค่าอ้างอิง ($m_{digital}$)
   - วางน้ำหนักลงบนแท่นโหลดเซลล์ทีละพิกัด (11 พิกัด ตั้งแต่ $0.988\text{ kg}$ ถึง $9.961\text{ kg}$)
   - บันทึกสัญญาณเวลา 15 วินาทีต่อพิกัดน้ำหนัก
   - ทำการทดลองซ้ำจนครบ 3 รอบ (Trial 1, 2, 3) รวมทั้งสิ้น 33 ชุดข้อมูล

### 4.2 เส้นโค้งการเทียบมาตรฐานและสมการถดถอยเชิงเส้น (Calibration Curve & Linear Regression)
เมื่อนำค่าน้ำหนักและแรงดันเฉลี่ยมาสร้างกราฟเทียบมาตรฐาน พร้อมหาเส้นถดถอยเชิงเส้นอันดับหนึ่ง (First-order Linear Regression) ดังแสดงในรูปที่ 1 ([Fig1_LoadCell_Voltage_vs_Mass.png](file:///C:/Users/Chard/Downloads/Lab1.4-20261003T065952Z-1-001/MATLAB%20Visualize/output_figures/Fig1_LoadCell_Voltage_vs_Mass.png))

จากรูปที่ 1 ได้ผลลัพธ์พารามิเตอร์ของระบบวัดดังนี้:
- **สมการการถดถอยเชิงเส้น (Linear Fit Model):**
  $$V_{out}(m) = 0.1702 \cdot m + 0.0580 \quad \text{[V]}$$
- **สัมประสิทธิ์การตัดสินใจ (Goodness-of-Fit):** $R^2 = 0.99525$
- **ความไวการวัดต่อมวล (Mass Sensitivity):** $S_m = 170.16\text{ mV/kg}$
- **ความไวการวัดต่อแรง (Force Sensitivity):** $S_F = 17.35\text{ mV/N}$ (คำนวณโดย $F = m \cdot 9.80665\text{ m/s}^2$)
- **แรงดันออฟเซตขณะไม่มีโหลด (Zero-Load Offset Voltage):** $V_0 = 0.0580\text{ V}$ ($71.9\text{ counts}$)
- **สมการการสอบเทียบย้อนกลับ (Inverse Calibration Model):**
  $$m(V_{out}) = 5.8490 \cdot V_{out} - 0.3117 \quad \text{[kg]}$$

### 4.3 พฤติกรรมสัญญาณที่พิกัดปลายสเกลและขอบเขต Saturation (High-Load Output Behavior)
เมื่อสังเกตพฤติกรรมของแรงดันเอาต์พุตในช่วงน้ำหนักสูงกว่า 8 kg ดังแสดงในรูปที่ 12b ([Fig12b_LoadCell_Saturation_SinglePlot.png](file:///C:/Users/Chard/Downloads/Lab1.4-20261003T065952Z-1-001/MATLAB%20Visualize/output_figures/Fig12b_LoadCell_Saturation_SinglePlot.png))

จากรูปที่ 12b มีข้อมูลเชิงตัวเลขที่บันทึกได้ดังนี้:
- ในช่วงมวล $0.988\text{ kg}$ ถึง $8.790\text{ kg}$ กราฟมีอัตราการเปลี่ยนแปลงแรงดันเฉลี่ย $\frac{\Delta V}{\Delta m} \approx 189.0\text{ mV/kg}$
- เมื่อมวลเกิน $8.790\text{ kg}$ เส้นกราฟเริ่มเบี่ยงเบนต่ำกว่าเส้นตรงเชิงเส้นในอุดมคติ (Ideal Linear Trajectory)
- ในช่วงระหว่าง $9.783\text{ kg}$ ถึง $9.961\text{ kg}$ แรงดันเปลี่ยนแปลงเพิ่มขึ้นเพียง $0.0144\text{ V}$ ทำให้อัตราการเปลี่ยนแปลงแรงดันลดลงเหลือ $\frac{\Delta V}{\Delta m} = 80.8\text{ mV/kg}$
- ค่าแรงดันสูงสุดหยุดอยู่ที่ระดับ $V_{sat} = 1.7196\text{ V} \approx 1.72\text{ V}$

# 5. สรุปผลการทดลอง (อธิบายสิ่งที่เกิดขึ้นในการทดลอง)

1. **การตอบสนองและย่านการวัด:** โหลดเซลล์ YZC-131A ร่วมกับวงจรขยาย INA125 และ STM32G474RE สามารถวัดแรงกด $9.69 - 97.68\text{ N}$ และสร้างแรงดันแอนะล็อก $0.1854 - 1.7196\text{ V}$ โดยแปรผันตรงเป็นเชิงเส้นอย่างยอดเยี่ยม ($R^2 = 0.99525$)
2. **คุณลักษณะที่ได้จากการทดลอง:** ระบบมีความไวต่อมวล $S_m = 170.16\text{ mV/kg}$, ความไวต่อแรง $S_F = 17.35\text{ mV/N}$, แรงดันออฟเซต $V_0 = 0.0580\text{ V}$ และได้สมการสอบเทียบย้อนกลับ: $m = 5.8490 \cdot V_{out} - 0.3117\text{ kg}$
3. **การปรับตั้งค่าอัตราขยาย:** การปรับตัวต้านทาน $R_G \approx 121\ \Omega$ ทำให้ได้อัตราขยาย $G \approx 500$ เท่า ซึ่งให้แรงดันสวิงสูงสุดไม่เกิน $1.72\text{ V}$ สำรอง Headroom $50\%$ ตามที่ออกแบบ
4. **พฤติกรรมสภาวะอิ่มตัว:** ที่น้ำหนักเกิน $8.79\text{ kg}$ เกิดสภาวะอิ่มตัว (Saturation) แรงดันหยุดนิ่งที่ระดับ $1.72\text{ V}$ และอัตราการเปลี่ยนแปลงแรงดันลดลงเหลือ $80.8\text{ mV/kg}$ (ลดลง $55\%$)
5. **ความคลาดเคลื่อนและการวัดซ้ำ:** ระบบมีความคลาดเคลื่อนเฉลี่ยเทียบกับเครื่องชั่งดิจิทัล $150.2\text{ g}$ ($1.51\% \text{ FS}$) สูงสุด $389.2\text{ g}$ ที่พิกัด $9.961\text{ kg}$ และการทดลองซ้ำ 3 รอบมีค่า Repeatability SD ต่ำมากเพียง $0.10 - 1.76\text{ mV}$ (สูงสุด $0.11\% \text{ FS}$)

# 6. อภิปรายผล (วิเคราะห์สิ่งที่เกิดขึ้นในการทดลอง)
*(หมายเหตุ: ส่วนนี้เป็นการวิเคราะห์ ตีความ อภิปรายสาเหตุทางวิศวกรรม และเชื่อมโยงทฤษฎีตามเอกสารและงานวิจัยที่เกี่ยวข้อง)*

**6.1 การตอบสนองของ Load Cell และวงจรขยาย INA125:**  
การต่อสเตรนเกจแบบ Full-Bridge Wheatstone Bridge [7] ให้ความไวสูงกว่าแบบ Quarter-Bridge ถึง 4 เท่า และหักล้างผลของอุณหภูมิในตัวเอง (Intrinsic Temperature Compensation) ทำให้แรงดันเอาต์พุตเป็นเชิงเส้นสูง ($R^2 = 0.99525$) ด้านไอซี INA125 [2] โครงสร้าง 2 Op-Amps มี Input Impedance $> 10^9\ \Omega$ ป้องกันผลกระทบโหลด (Loading Effect) ต่อบริดจ์ และมี CMRR $> 100\text{ dB}$ ช่วยตัดแรงดันกึ่งกลางบริดจ์ ($1.65\text{ V}$) จึงขยายสัญญาณผลต่างขนาดเล็ก $V_d = V^+ - V^- = 4.3\text{ mV}$ สู่ระดับโวลต์ได้อย่างเสถียร

**6.2 การคำนวณ Gain และความสัมพันธ์กับตัวต้านทาน $R_G$:**  
ผลต่างแรงดันอินพุตที่วัดได้จริงจากขาสัญญาณโหลดเซลล์คือ $V_d = V^+ - V^- = 4.3\text{ mV}$ (เทียบกับพิกัดคำนวณตามทฤษฎี $1.0\text{ mV/V} \times 3.3\text{ V} = 3.30\text{ mV}$) เพื่อสำรอง Headroom $50\%$ ของไฟเลี้ยง $3.3\text{ V}$ ป้องกันสัญญาณชนขอบ จึงกำหนด $V_{out\_max} \approx 1.72\text{ V}$ คำนวณอัตราขยายเป้าหมายได้ $G \approx \frac{1.72 - 0.058}{0.0043} \approx 387$ เท่า (และเมื่อออกแบบเผื่อตามสเปกทฤษฎีจะได้ $G \approx 500$ เท่า โดยใช้ $R_G \approx 121 - 152\ \Omega$) [2] ทั้งนี้ ความสัมพันธ์ $G$ กับ $R_G$ เป็นฟังก์ชันผกผันไฮเพอร์โบลา ($\partial G / \partial R_G \propto -1/R_G^2$) ในย่าน $R_G$ ต่ำ ความไวต่อการเปลี่ยนค่าสูงมาก จึงจำเป็นต้องใช้ Trimpot 25 รอบเพื่อปรับจูนได้อย่างละเอียดและมีเสถียรภาพ

**6.3 กระบวนการ Signal Conditioning และ Calibration:**  
ระบบทำงาน 5 ขั้นตอน: 1) Transduction แปลงแรงกดเป็น $\Delta R$ ผ่าน Full-Bridge, 2) Amplification & CMRR ขยายสัญญาณผลต่างด้วย INA125, 3) Sampling & Filtering สุ่มสัญญาณด้วย ADC 12-bit (STM32) พร้อม Moving Average, 4) Tare หักลบ Offset ($V_0 = 0.058\text{ V}$), และ 5) Linear Scaling แปลงเป็นมวล ($m$) และแรง ($F$) ในหน่วยอนุพันธ์ SI

**6.4 การวิเคราะห์สาเหตุของสภาวะ Saturation:**  
ที่มวล $> 8.79\text{ kg}$ แรงดันคงที่อยู่ที่ $V_{sat} \approx 1.72\text{ V}$ (ความชันตกลง $55\%$) ซึ่ง**ไม่ใช่** Op-Amp Rail Saturation เนื่องจาก INA125 มีเพดานสวิงสูงถึง $2.1 - 3.8\text{ V}$ [2] วงจรไฟฟ้ายังมี Headroom เหลือ แต่สาเหตุแท้จริงเกิดจาก **Mechanical Overload Protection Stop** [1] เมื่อคานโก่งตัวจนแตะฐานรองรับ ความแข็งเกร็งจะเพิ่มขึ้นทันที (Non-linear Stiffening) สเตรนเกจจึงไม่เกิดความเครียดเพิ่มขึ้น

**6.5 การวิเคราะห์สาเหตุความคลาดเคลื่อนเทียบกับเครื่องชั่งดิจิทัล:**  
Error เฉลี่ย $150.2\text{ g}$ (สูงสุด $389.2\text{ g}$ ที่ปลายสเกล) มีสาเหตุหลัก 5 ประการ: 1) Off-Center Error จากการวางน้ำหนักเยื้องศูนย์และคอดคานไม่สมมาตร [5, 6], 2) ปรากฏการณ์ Creep และ Hysteresis จากการคลายตัวหยุ่นหนืดของเนื้ออะลูมิเนียมและกาวประสาน [3, 4], 3) Thermal Drift จากความร้อนสะสมของบริดจ์ [7, 8], 4) USB Switching Noise ($2.59\text{ mV}$ RMS) และ 5) ความไม่เป็นเชิงเส้นตกค้างจากการประมาณด้วยสมการเส้นตรง [10]

**6.6 ความสามารถในการวัดซ้ำเทียบกับมาตรฐาน OIML R60:**  
การวัดซ้ำ 3 รอบให้ Repeatability SD สูงสุดเพียง $1.76\text{ mV}$ ($0.11\% \text{ FS}$) สอดคล้องตามเกณฑ์มาตรฐานสากล OIML R60 Class D [9] ยืนยันความเสถียรและความน่าเชื่อถือสูง

# 7. ข้อเสนอแนะ (Recommendations)

1. **Polynomial Compensation:** ใช้สมการพหุนามกำลังสอง ($V_{out} = -0.0039m^2 + 0.2128m - 0.0245$) บน STM32 เพื่อชดเชยความโค้งปลายสเกล ลด Error เหลือ $2.75\% \text{ FS}$ [10]
2. **การวัดและปรับตั้งค่าความต้านทาน $R_G$ นอกวงจร:** เนื่องจากการวัดค่า Trimpot ขณะต่ออยู่ในวงจร (In-Circuit) มีโอกาสคลาดเคลื่อนจากผลกระทบของวงจรภายในไอซี จึงควรวัดและปรับตั้ง Trimpot นอกวงจรก่อนนำมาต่อ หรือเปลี่ยนมาใช้ตัวต้านทานคงที่ความแม่นยำสูง (Precision Resistor 0.1%, $121\ \Omega$) เพื่อขจัดความคลาดเคลื่อนและความไม่เสถียรของหน้าสัมผัส
3. **แหล่งจ่ายไฟแยกและพัลส์กระตุ้น:** ใช้ไอซี LDO แยกจ่ายไฟแอนะล็อกเพื่อลด USB Noise ($2.59\text{ mV}$) และใช้เทคนิค Pulsed Excitation ลดความร้อนสะสม [7]
4. **Self-Centering Fixture:** ออกแบบแท่นวาง 3D-Printed ให้มีร่องล็อกศูนย์ถ่วงเพื่อขจัด Four-Corner Error [5]

# ภาคผนวก จ: การปรับสภาพสัญญาณและการสอบเทียบโหลดเซลล์ (Lab 1.4)

### จ.1 การคำนวณค่า Gain ที่เหมาะสม และค่าตัวต้านทาน $R_G$
1. **พารามิเตอร์ของโหลดเซลล์ YZC-131A:**
   - พิกัดรับน้ำหนักสูงสุด (Rated Capacity): $10\text{ kg}$
   - ความไวพิกัด (Rated Output Sensitivity): $1.0 \pm 0.15\text{ mV/V}$
   - แรงดันกระตุ้น (Excitation Voltage): $V_{exc} = 3.30\text{ V}$
   - สัญญาณผลต่างแรงดันสูงสุดที่พิกัดเต็มสเกลตามทฤษฎี:
     $$V_{d\_theory} = 1.0\text{ mV/V} \times 3.30\text{ V} = 3.30\text{ mV}$$
   - **สัญญาณผลต่างแรงดันที่วัดได้จริงในการทดลอง (Differential Voltage Measured):**
     $$V_d = V^+ - V^- = 4.30\text{ mV}$$
     (ค่าที่วัดได้จริง $4.30\text{ mV}$ สูงกว่าค่าทฤษฎีเล็กน้อยจากพิกัดความเผื่อความไวของโหลดเซลล์ $\pm 0.15\text{ mV/V}$, ความไม่สมดุลเริ่มต้นของวงจรบริดจ์ และแรงกดเริ่มต้นจากแท่น 3D-Printed)
2. **การกำหนดช่วงแรงดันเอาต์พุตและสำรอง Headroom:**
   - แรงดันไฟเลี้ยงระบบของไมโครคอนโทรลเลอร์ STM32 คือ $3.30\text{ V}$
   - เพื่อป้องกันปัญหาสัญญาณชนขอบเพดานไฟเลี้ยง (ADC Saturation / Clipping) เมื่อเกิดแรงกระแทกพลวัต จึงสำรอง Dynamic Headroom ไว้อย่างน้อย $45\% - 50\%$ โดยกำหนดให้แรงดันเอาต์พุตสูงสุดที่โหลด 10 kg อยู่ที่ประมาณ $V_{out\_max} \approx 1.72\text{ V}$
   - เมื่อหักลบแรงดันออฟเซตเริ่มต้นขณะไม่มีโหลด ($V_0 = 0.0580\text{ V}$) จะได้ช่วงการแกว่งของแรงดันสุทธิ:
     $$\Delta V_{out} = 1.720\text{ V} - 0.058\text{ V} = 1.662\text{ V}$$
3. **การคำนวณค่า Gain เป้าหมาย ($G_{target}$):**
   - คำนวณจากสัญญาณผลต่างที่วัดได้จริง ($V_d = 4.30\text{ mV}$):
     $$G_{actual} = \frac{\Delta V_{out}}{V_d} = \frac{1.662\text{ V}}{0.0043\text{ V}} \approx 386.5 \approx 387\text{ เท่า}$$
   - (หรือกรณีคำนวณตามพิกัดทฤษฎี $V_{d\_theory} = 3.30\text{ mV}$: $G_{theory} = \frac{1.662\text{ V}}{0.0033\text{ V}} \approx 500\text{ เท่า}$)
4. **การคำนวณหาค่าความต้านทาน $R_G$:**
   ตามเอกสารข้อมูลของไอซี INA125 [2] สมการอัตราขยายกำหนดโดย:
   $$G = 4 + \frac{60\text{ k}\Omega}{R_G} \implies R_G = \frac{60\text{ k}\Omega}{G - 4}$$
   - สำหรับ $G \approx 387$ เท่า (จากค่าจริง $4.3\text{ mV}$):
     $$R_G = \frac{60{,}000\ \Omega}{387 - 4} = \frac{60{,}000}{383} \approx 156.66\ \Omega \approx 157\ \Omega$$
   - สำหรับ $G \approx 500$ เท่า (จากค่าทฤษฎี $3.3\text{ mV}$):
     $$R_G = \frac{60{,}000\ \Omega}{500 - 4} = \frac{60{,}000}{496} \approx 120.97\ \Omega \approx 121\ \Omega$$
   - ดังนั้น ในการทดลองจึงใช้ย่านความต้านทาน $R_G \approx 121 - 157\ \Omega$ ในการปรับตั้ง
5. **การวิเคราะห์ความสัมพันธ์ $G$ กับ $R_G$ และการเลือกใช้อุปกรณ์ปรับค่า:**
   - สมการอัตราขยายเป็นฟังก์ชันผกผันไฮเพอร์โบลา ($\frac{dG}{dR_G} = -\frac{60{,}000}{R_G^2}$)
   - ที่จุดทำงาน $R_G \approx 121 - 157\ \Omega$ อนุพันธ์ความชันมีค่าเท่ากับ $\frac{dG}{dR_G} \approx -2.4 \text{ ถึง } -4.1\text{ per }\Omega$ หมายความว่าหากความต้านทานคลาดเคลื่อนเพียง $1\ \Omega$ อัตราขยายจะเปลี่ยนไปถึง $2.4 - 4.1$ เท่า
   - ดังนั้นจึงจำเป็นต้องใช้ตัวต้านทานปรับค่าได้ชนิดละเอียด Multi-turn Trimpot ขนาด $100\text{ k}\Omega$ จำนวน 25 รอบ ต่อร่วมกับตัวต้านทานคงที่จำกัดค่า เพื่อให้สามารถหมุนปรับจูนค่าได้อย่างละเอียด แม่นยำ และมีความเสถียรเชิงกล

### จ.3 การหาสมการ Calibration Curve เพื่อแปลง Voltage ขาออกเป็นค่าน้ำหนักจริง (SI Units)
1. **การสร้างเส้นโค้งเทียบมาตรฐาน (Calibration Curve):**
   จากข้อมูลการทดลองเฉลี่ย 3 รอบซ้ำ (11 พิกัดน้ำหนัก $0.988 - 9.961\text{ kg}$) เมื่อนำมาคำนวณหาสมการถดถอยเชิงเส้นอันดับหนึ่ง (Linear Regression) จะได้สมการแสดงแรงดันเอาต์พุตตามมวล:
   $$V_{out}(m) = S_m \cdot m + V_0 = 0.1702 \cdot m + 0.0580 \quad \text{[V]}$$
   - ความไวเชิงมวล (Mass Sensitivity): $S_m = 170.16\text{ mV/kg} = 0.1702\text{ V/kg}$
   - แรงดันออฟเซตขณะไม่มีโหลด (Zero Load Offset): $V_0 = 0.0580\text{ V}$
   - สัมประสิทธิ์การตัดสินใจ: $R^2 = 0.99525$
2. **สมการการสอบเทียบย้อนกลับ (Inverse Calibration Curve):**
   เพื่อแปลงแรงดันแอนะล็อกที่วัดได้กลับมาเป็นค่าน้ำหนักจริงในหน่วยกิโลกรัม ($\text{kg}$):
   $$m(V_{out}) = \frac{V_{out} - V_0}{S_m} = \frac{V_{out} - 0.0580}{0.1702} = 5.8490 \cdot V_{out} - 0.3117 \quad \text{[kg]}$$
3. **การแปลงเป็นแรงกดในหน่วยอนุพันธ์ SI (Newton: N):**
   ตามกฎข้อที่สองของนิวตัน ($F = m \cdot g$) โดยใช้ค่าความเร่งโน้มถ่วงมาตรฐาน $g = 9.80665\text{ m/s}^2$:
   $$F(V_{out}) = m(V_{out}) \cdot 9.80665 = (5.8490 \cdot V_{out} - 0.3117) \times 9.80665$$
   $$F(V_{out}) = 57.359 \cdot V_{out} - 3.057 \quad \text{[N]}$$
   - ความไวเชิงแรง (Force Sensitivity): $S_F = \frac{S_m}{g} = \frac{170.16\text{ mV/kg}}{9.80665\text{ m/s}^2} = 17.35\text{ mV/N}$

### จ.4 การตั้งค่าโมเดล Simulink และเฟิร์มแวร์บน STM32G474RE แบบ Real-time
1. **การตั้งค่าฮาร์ดแวร์และ ADC:**
   - ไมโครคอนโทรลเลอร์: STM32G474RE (ARM Cortex-M4 Core @ 170 MHz)
   - โมดูล ADC: ADC1 Regular Channel 1 ต่อเข้าขา PA0
   - ความละเอียด: 12-bit Resolution ($0 - 4095\text{ counts}$) สอดคล้องกับย่านแรงดัน $0 - 3.30\text{ V}$
   - อัตราการสุ่มสัญญาณ (Sampling Rate): $1\text{ kHz}$ (Sample Time $T_s = 0.001\text{ s}$)
2. **ลำดับขั้นการประมวลผลข้อมูล (Data Acquisition Pipeline):**
   $$\text{ADC Raw (12-bit)} \xrightarrow{\times \frac{3.3}{4095}} V_{out}\text{ [V]} \xrightarrow{5.8490 \times V - 0.3117} \text{Mass [kg]} \xrightarrow{\times 9.80665} \text{Force [N]}$$
3. **บล็อกไดอะแกรมใน Simulink:**
   - **บล็อก Regular ADC:** กำหนด Sample Time $= 0.001$ อ่านสัญญาณจาก PA0
   - **บล็อก Gain 1:** คูณค่าด้วย $\frac{3.30}{4095} \approx 0.00080586$ เพื่อแปลงเป็นโวลต์ ($V_{out}$)
   - **บล็อก Bias:** หักลบค่า Offset $-0.0580$
   - **บล็อก Gain 2:** คูณค่าความชันย้อนกลับ $5.8490$ ได้มวลในหน่วย $\text{kg}$
   - **บล็อก Saturation (Tare Clamping):** จำกัดขอบเขตล่างที่ $0.0\text{ kg}$ ป้องกันตัวเลขติดลบ
   - **บล็อก Gain 3:** คูณค่า $9.80665$ แปลงเป็นแรงในหน่วย $\text{N}$
   - **บล็อก Scope / UART Tx:** แสดงรูปคลื่นพลวัตและส่งค่าผ่านพอร์ตสื่อสารแบบ Real-time
4. **โค้ดเฟิร์มแวร์ภาษา C บน STM32:**
```c
/* ====================================================================
 * Firmware Real-time Signal Conditioning & Calibration Algorithm
 * Target: STM32G474RE | ADC1 Channel 1 (Pin PA0) | Sampling Rate: 1 kHz
 * ==================================================================== */
#define ADC_MAX_COUNT       4095.0f
#define V_REF               3.30f
#define CAL_SLOPE_INV       5.8490f     // Inverse calibration slope (kg/V)
#define CAL_OFFSET_INV      0.3117f     // Inverse offset (kg)
#define GRAVITY_CONSTANT    9.80665f    // Standard gravity (m/s^2)

void Process_LoadCell_Sample(void)
{
    // 1. อ่านค่าดิจิทัลจาก ADC 12-bit
    uint16_t raw_adc = HAL_ADC_GetValue(&hadc1);
    
    // 2. แปลงค่าดิบเป็นแรงดันไฟฟ้าแอนะล็อก (Voltage Scaling)
    float v_out = ((float)raw_adc / ADC_MAX_COUNT) * V_REF;
    
    // 3. แปลงแรงดันเป็นมวลจริงตามสมการ Inverse Calibration (SI: kg)
    float mass_kg = (CAL_SLOPE_INV * v_out) - CAL_OFFSET_INV;
    
    // ซอฟต์แวร์ Tare Clamping ป้องกันค่ามวลติดลบขณะไม่มีโหลด
    if (mass_kg < 0.0f) {
        mass_kg = 0.0f;
    }
    
    // 4. แปลงมวลเป็นแรงกดในหน่วยอนุพันธ์ SI (Force: N)
    float force_N = mass_kg * GRAVITY_CONSTANT;
    
    // 5. ส่งค่าออกไปยังระบบมอนิเตอร์และคอนโทรลเลอร์แบบ Real-time
    Transmit_Telemetry(v_out, mass_kg, force_N);
}
```
